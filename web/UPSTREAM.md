# Frontend provenance

This frontend is maintained as part of ATID CLI Proxy.

Imported from https://github.com/router-for-me/Cli-Proxy-API-Management-Center
at commit `390718ecfec90b674fed474862e497522273e129`. The upstream license is preserved in `LICENSE`.

Build with `make web-build` from the repository root. The single-file output is
served by the local backend at `/management.html`.
