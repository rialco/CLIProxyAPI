# ATID CLI Proxy — Management UI

React and TypeScript frontend for ATID CLI Proxy. See [the project guide](../DEVELOPMENT.md)
and [upstream provenance](UPSTREAM.md).

From the repository root, run `make web-build` to build and install the single-file
panel, or `make dev` to build both components and start the local server.

Use `bun run verify` in this directory for frontend tests, lint, and production build.
